# Aurum 50

Eigenständiger 3D-Rundgang durch ein Hochhaus mit 50 Ebenen, von der Lobby bis zur Aussichtsetage. Die bronzefarbene Glasfassade zeigt den beleuchteten Treppenkern. Die 49 Etagenübergänge sind über je zwei Treppenläufe und ein Zwischenpodest verbunden.

## Starten

Im Projektordner `python3 -m http.server 8080` starten und anschließend http://localhost:8080 öffnen. Für GitHub Pages liegt `index.html` direkt im Projektstamm. Alle Laufzeitdateien werden lokal mitgeliefert.

Auf dem Smartphone links ziehen zum Gehen, rechts ziehen zum Umsehen. Am Rechner mit WASD laufen und mit gedrückter Maustaste umsehen. Über **Orte** sind alle Etagen direkt erreichbar.

## Panoramaaufzug

An der Rückseite jeder Etage findest du die Glaskabine. Warte gegebenenfalls am Portal und tippe auf **Aufzug rufen**. Nach dem Einsteigen öffnet **Etage wählen** die Ziele von der Lobby bis zur 50. Etage. Die Fahrt findet im Gebäude statt und die Türen öffnen am Ziel automatisch. Die getönten Fassadenscheiben bleiben von beiden Seiten durchsichtig.
